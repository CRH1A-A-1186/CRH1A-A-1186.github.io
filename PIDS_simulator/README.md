# 地铁 PIDS 显示器模拟器

使用100%vibe coding制作的纯前端的地铁乘客信息系统（PIDS）显示屏模拟器。在浏览器中模拟地铁车厢内 LCD 显示屏的线路图、到站信息和实时运行状态。

> **在线体验**: 访问 [njfdCRH1A.github.io](https://njfdCRH1A.github.io) 并导航至 PIDS 模拟器页面

## 功能概览

### 🚇 PIDS 显示屏

- **顶部横幅**: 显示当前站/下一站名称、开往方向、当前时间
- **线路轨道图**: SVG 渲染的线路走向，包含站点圆圈、站名、到站时间和方向箭头
- **停站状态**: 停站时当前站名显示红色，站台圆圈黄色闪烁
- **区间运行**: 当前运行区间的箭头闪烁动画，指示列车行进方向

### 🎛️ 线路控制

| 控制项 | 说明 |
|--------|------|
| 线路颜色 | 线路轨道和站点圆圈的颜色 |
| 横幅文字颜色 | 顶部横幅的时间/站名文字颜色（浅色/深色） |
| 站名颜色 | 线路图中站名的默认颜色（停站时当前站强制红色） |
| 运行方向 | 左行（←）或右行（→），影响箭头方向和视觉排列 |
| 线路长度 | 线路在 display 中的水平长度（10–300） |
| 线路粗细 | 轨道线条粗细（1–20） |
| 线路位置 | 轨道在 display 中的垂直位置（0=顶部, 1=底部） |

### 🚉 车站管理

- **添加车站**: 在末尾新增车站，自动分配站名
- **删除车站**: 删除任意车站（至少保留 1 个）
- **拖拽排序**: 拖拽车站卡片调整顺序
- **一键反向**: 反转全部车站顺序，同步更新当前站位置
- **重置车站**: 恢复默认车站列表

每个车站可编辑：
- 中文站名、英文副站名
- 到下一站的运行时间（分钟）
- 车站类型（普通站 / 换乘站）

### 🚆 换乘站支持

将车站类型设为「换乘站」后：
- 可添加多条换乘线路及其颜色
- 线路图中换乘站显示为换乘图标（`transfer.svg`）
- 换乘线路框以 3 秒间隔闪烁提示
- 已过站的换乘图标自动变灰

### 🏃 画面切换控制

| 按钮 | 功能 |
|------|------|
| ⏮ 起点 | 跳转到起点站（停站状态） |
| ◀ 上一步 | 退回一站或返回停站状态 |
| ▶ 自动运行 | 以 3 秒间隔自动推进 |
| 下一步 ▶ | 前进一站或发车进入区间 |

运行逻辑：**停站 → 发车（区间运行）→ 到站停站 → 发车 → …**，到达终点站后循环回起点。

### 🎨 站名显示模式

4 种站名排列方式，适应不同线路密度：

| 模式 | 效果 |
|------|------|
| 横向上下交错式 | 偶数站名在上、奇数站名在下，交替排列 |
| 右上角斜 45° 式 | 站名沿 45° 方向延伸，紧凑排列 |
| 站点上方垂直式 | 竖排文字在站点上边 |
| 站点下方垂直式 | 竖排文字在站点下边 |

### ⚙️ 其他可调参数

- **列车编组**: 自定义车厢号与类型（车头朝向/中间车），影响停止位置计算
- **停止位置**: 前部对标 / 居中对标 / 尾部对标
- **站点图标尺寸**: 2–10（可调）
- **箭头高度/宽度/颜色/描边粗细**: 独立可调
- **箭头闪烁速度**: 100–2000ms
- **站名字号**: 2–8（可调）
- **PIDS 背景**: 纯色 / 纹理图片（拉伸/完整/平铺），支持透明度调节

### ⏰ 时间显示

- **系统时间**: 使用浏览器当前时间，自动更新
- **手动时间**: 可自行设定年月日时分

### 💾 数据持久化

- **自动保存**: 所有配置自动保存到浏览器 localStorage，刷新不丢失
- **导出配置**: 导出为 `.json` 文件备份
- **导入配置**: 从 `.json` 文件恢复配置

## 使用方法

1. 用浏览器直接打开 `index.html`（无需服务器、无需安装）
2. 左侧面板调整线路外观和参数
3. 右下角车站编辑区添加/编辑车站
4. 使用底部播放控制栏模拟列车运行
5. 所有修改实时反映在右侧 PIDS 显示屏中

## 技术架构

| 项目 | 说明 |
|------|------|
| 依赖 | **零依赖** — 无 npm 包、CDN、第三方库 |
| 运行方式 | 纯静态 — 浏览器直接打开 `index.html` |
| JS | 原生 ES6+，单文件 `main.js`（约 2700 行） |
| CSS | 原生 CSS3（Flexbox + CSS 变量），单文件 `style.css` |
| 图形 | 内联 SVG（线路图、箭头、换乘图标） |
| 存储 | localStorage（自动保存 + 导出/导入 JSON） |
